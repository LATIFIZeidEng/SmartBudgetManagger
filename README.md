# SmartBudgetManagger

SmartBudget Manager is an Excel workbook to record income and expenses and see your balance and budget status.

You need Excel 2016 or newer and the file `SmartBudget_Manager.xlsx`.

## How to start

1. Open the file and click **Enable Editing** if Excel asks.
2. In the **Categories** sheet, set the monthly budget of each category.
3. In the **Transactions** sheet, delete the sample data in cells A4:G9 (do not delete column H).
4. Add your transactions in the next empty row.
5. Look at the **Dashboard** sheet to see the results.
